# GAVAC - Sistema de Gestión Ganadera

## Descripción

GAVAC es una aplicación web y móvil para la gestión de informacion ganaderas.

El sistema permitirá administrar el ciclo de vida de los animales, desde su registro hasta su venta o fallecimiento, además de controlar la sanidad, inventario, veterinarios y generar reportes en PDF.

---

## Objetivos

- Registrar animales.
- Gestionar historial del animal.
- Controlar sanidad.
- Administrar inventario.
- Gestionar usuarios.
- Registrar veterinarios.
- Generar reportes en PDF.
- Desarrollar aplicación web y móvil.
