# Modelo de Datos - GAVAC

## Objetivo

Este documento describe la estructura de la base de datos del sistema GAVAC (Sistema de Gestión Ganadera).

Su propósito es definir todas las entidades, sus atributos, relaciones y reglas de negocio antes de implementarlas en Prisma y PostgreSQL.

## Estado del proyecto

### Finalizado

- Estructura inicial del proyecto.
- Configuración del backend con Node.js, Express y TypeScript.
- Configuración de Prisma ORM.
- Conexión con PostgreSQL.
- Primera migración.
- Tabla Raza creada correctamente.
